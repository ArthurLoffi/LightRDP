# Visual assets
The LightRDP logo and README card.

| File | Use |
| --- | --- |
| `logo_mark.svg` | The mark alone (app icon, favicon). Scales to any size. |
| `logo_dark.png` | Horizontal logo for dark backgrounds. Transparent background. |
| `logo_light.png` | Horizontal logo for light backgrounds. Transparent background. |
| `readme_card.png` | 1280×640 card, shown at the top of `README.md`. Also fits the GitHub social preview. |

PNG files are exported at 2x.

## The mark
A screen outline with a cursor that breaks out of its frame: one machine reaching into another. The wordmark sets "Light" in a thin weight and "RDP" in bold.

## Colors
| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#0F1419` | Backgrounds, text on light |
| Paper | `#F5F6F3` | Text on dark, light backgrounds |
| Signal | `#FFC53D` | The cursor, highlights |
| Slate | `#9AA6B2` | Secondary text on dark |

## Fonts
- [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk): logo and headings.
- [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono): terminal and code.
