# Host did not answer in time
**Message:** `erro: conexão recusada: tempo esgotado aguardando o host`

## Description
Nobody accepted your connection request on the host within 60 seconds.

## Cause
The host must answer `Aceitar? [s/N]` within 60 seconds. If nobody answers, the request is refused.

## Possible solution
- Ask the person at the host to watch the host terminal.
- Try again.
