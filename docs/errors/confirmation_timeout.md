# Host did not answer in time
**Message:** `error: connection refused: timed out waiting for host`

## Description
Nobody accepted your connection request on the host within 60 seconds.

## Cause
The host must answer `Accept? [y/N]` within 60 seconds. If nobody answers, the request is refused.

## Possible solution
- Ask the person at the host to watch the host terminal.
- Try again.
