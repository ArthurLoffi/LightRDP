# Host busy
**Message:** `erro: conexão recusada: host ocupado`

## Description
The host refused the connection because it is already in a session with someone else.

## Cause
A host accepts only one session at a time.

## Possible solution
- Wait for the current session to end and try again.
- Ask the person on the host machine to restart the host.
