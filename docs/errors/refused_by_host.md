# Refused by the host
**Message:** `erro: conexão recusada: recusado pelo host`

## Description
The person at the host refused your connection request.

## Cause
When a connection request arrives, the host is asked `Aceitar? [s/N]`. Any answer other than `s`, including just pressing Enter, refuses the request.

## Possible solution
- Confirm with the person at the host that they expect your connection.
- Try again and ask them to answer `s`.
