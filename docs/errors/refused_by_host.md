# Refused by the host
**Message:** `error: connection refused: refused by host`

## Description
The person at the host refused your connection request.

## Cause
When a connection request arrives, the host is asked `Accept? [y/N]`. Any answer other than `y`, including just pressing Enter, refuses the request.

## Possible solution
- Confirm with the person at the host that they expect your connection.
- Try again and ask them to answer `y`.
